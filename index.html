Guide使い方How to use

  1. Serato と連携する

    Connect Serato

    「Seratoと連携」を押して、ミュージックフォルダの中の「_Serato_」フォルダを選びます。Serato のライブラリ（BPM・キー・ジャンル）をそのまま読み込みます。最初の一度だけで、次からは自動でつながります。

    Click “Connect Serato” and choose the “_Serato_” folder inside your Music folder. Your Serato library (BPM, key, genre) is loaded as is. You only do this once; it reconnects automatically after that.

  2. Serato で曲をかける

    Play a track in Serato

    デッキに曲を読み込むと、数秒で「次に合う曲」が並びます。大きな数字は相性の点数（100点満点）、BPM の横の +1.9% などは今の曲からのテンポの差です。

    Load a track on a deck and the best next tracks appear within seconds. The big number is the match score (out of 100); values like +1.9% show the tempo difference from the current track.

    8A→9A8A→10A8A→3B

    キーの色は、緑＝安全、黄＝エナジーブースト系、赤＝ぶつかる可能性あり、です。

    Key colors: green = safe, yellow = energy boost, red = may clash.

  3. 候補をクリック → Serato で ⌘F ⌘V

    Click a suggestion → ⌘F ⌘V in Serato

    候補をクリックすると「アーティスト名 曲名」がコピーされます。Serato で ⌘F（検索）→ ⌘V（貼り付け）すると、その曲が Clean / Dirty などの別バージョンと一緒にすぐ出てきます。

    Clicking a suggestion copies “Artist Title”. In Serato, press ⌘F (search) then ⌘V (paste) to find it instantly, together with other versions such as Clean / Dirty.

  4. ブースの横に置く

    Keep it next to Serato

    ウィンドウを細くすると小さい表示になります。📌 で常に手前（Serato が全画面でも上に出ます）、◐ で透明度を変えられます。▲ 上げる／▼ 落とす、系統ボタン（HipHop・R&B・Dance…）で候補を絞れます。

    Make the window narrow for the compact view. 📌 keeps it on top (even over full-screen Serato) and ◐ changes transparency. Use ▲ Up / ▼ Down and the style buttons (HipHop, R&B, Dance…) to narrow the suggestions.

FAQよくある質問Frequently asked questions

候補が出ませんNo suggestions appear

Serato と連携しているか（画面下の「Serato 接続中」）を確認してください。BPM やキーが未解析の曲は候補に出ないので、Serato で曲を解析（Analyze）してから「Seratoのライブラリを読み込み直す」を押してください。無料版では Dance・HipHop 以外の曲で選曲できません。

Check that Serato is connected (“Serato connected” at the bottom). Tracks without BPM or key are skipped, so analyze them in Serato and then choose “Reload Serato library”. The free version works only for Dance and HipHop tracks.

今の曲が切り替わりませんThe current track does not update

Serato がデッキに曲を読み込んでから、数秒で反映されます。反映されない場合は、⚙ ›「診断情報をコピー」を押して、その内容をお問い合わせ先に送ってください。急ぎのときは「今の曲を手動で選ぶ」で指定できます。

It updates a few seconds after Serato loads a track on a deck. If it does not, choose ⚙ › “Copy diagnostics” and send the result to us. In a hurry, use “Pick the current track manually”.

Serato を全画面にすると見えなくなりますIt disappears when Serato is full screen

📌（常に手前に表示）をオンにしてください。全画面の Serato の上にも表示されます。オンの間は Dock とメニューバーからアイコンが消えるので、終了は小さい表示の右上の ✕ から行います。

Turn on 📌 (Always on top). The window then stays over full-screen Serato. While it is on, the app leaves the Dock and menu bar, so quit with the ✕ in the compact view.

曲の系統（HipHop・Dance など）が違いますA track shows the wrong style

系統は Serato のジャンルタグから判定します。「MainStream」やタグなしの曲は、同じアーティストの他の曲から推測します。Serato でジャンルを直して、ライブラリを読み込み直すと反映されます。

Styles come from the genre tags in Serato. Tracks tagged “MainStream” or left blank are guessed from the same artist’s other tracks. Fix the genre in Serato and reload the library.

Last.fm 連携とは？What is the Last.fm feature?

今の曲と「一緒に聴かれている曲・アーティスト」を Last.fm から取り、クラブの定番のつなぎを「定番」ラベル付きで上位に出す機能です。使わなくても選曲はできます。

It gets tracks and artists that are often played together with the current track from Last.fm and ranks proven transitions higher with a “Classic” label. Suggestions work without it too.

API キーはご自身で無料で作ります：API アカウント作成ページで Application name だけ入力して Submit → 表示された「API key」（32文字）をアプリの ⚙ › Last.fm の設定 に貼り付けます。Shared secret は使いません。

Create your own free API key: on the API account page, enter only an Application name and click Submit, then paste the “API key” (32 characters) into ⚙ › Last.fm settings in the app. The Shared secret is not used.

別の Mac で Pro を使いたい／買い直したくないUse Pro on another Mac without paying again

同じ Apple ID でサインインした Mac なら、Pro の画面で「購入を復元」を押すと無料で使えます。

On any Mac signed in with the same Apple ID, click “Restore purchase” on the Pro screen.

PrivacyプライバシーポリシーPrivacy Policy

制定日：2026年11月7日Effective: November 7, 2026

1. 収集する情報

1. Information we collect

Mix Support DJ（以下「本アプリ」）は、利用者の個人情報を収集しません。アカウント登録はなく、利用状況の分析（アナリティクス）、広告、トラッキングも行いません。

Mix Support DJ (“the app”) does not collect personal information. There is no account, and the app uses no analytics, advertising or tracking.

2. 本アプリが読み取るデータ

2. Data the app reads

  • 利用者が選んだ「_Serato_」フォルダ内のライブラリ情報（曲名・アーティスト・BPM・キー・ジャンル）と再生ログ。今かけている曲を知るためだけに読み取り、書き換えはしません。
  • 利用者が追加した音楽ファイル。BPM とキーの解析のためだけに読み取ります。
  • Library information (title, artist, BPM, key, genre) and play logs inside the “_Serato_” folder you choose. They are read only to find the track you are playing and are never modified.
  • Music files you add, read only to detect their BPM and key.

これらの処理はすべて利用者の Mac の中で行い、外部に送信しません。

All of this happens on your Mac and nothing is sent anywhere.

3. Last.fm 連携（任意）

3. Last.fm (optional)

利用者が自分の Last.fm API キーを設定した場合に限り、今かけている曲の「アーティスト名と曲名」と、その API キーを Last.fm の API に送信し、似た曲・アーティストの情報を受け取ります。受け取った情報は利用者の Mac に最大30日間保存します。Last.fm での情報の扱いは Last.fm のプライバシーポリシーをご確認ください。設定しなければ通信は一切行いません。

Only if you enter your own Last.fm API key, the app sends the artist and title of the current track, together with that key, to the Last.fm API and receives similar tracks and artists. The results are stored on your Mac for up to 30 days. See the Last.fm Privacy Policy for how Last.fm handles data. Without a key, the app makes no network requests.

4. 購入

4. Purchases

Pro の購入は Apple の App Store を通じて行われます。支払い情報は Apple が管理し、開発者が受け取ることはありません。

Pro is purchased through Apple’s App Store. Apple handles payment information; the developer never receives it.

5. 端末内に保存するデータ

5. Data stored on your Mac

表示の設定、連携した _Serato_ フォルダの場所、Last.fm の API キーと結果のキャッシュを、利用者の Mac の中にだけ保存します。本アプリを削除すると、これらも削除されます。

Display settings, the location of the linked _Serato_ folder, your Last.fm API key and its result cache are stored only on your Mac. They are removed when you delete the app.

6. Changes and contact

本ポリシーを変更する場合は、このページで更新します。ご質問は上の「お問い合わせ」のメールアドレスまでお送りください。

Any changes to this policy will be posted on this page. For questions, email the address under “Contact” above.
